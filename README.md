# Python To-Do List

## 📌 Project 1 – Python Programming

This project is a simple **To-Do List application** developed in Python as part of the DecodeLabs Python Programming Project 1.

The main purpose of this project is to practice **data management using Python lists**. Users can add tasks to a list and view their tasks.

## 🎯 Project Objective

The objective is to build a program that allows users to:

* Add new tasks
* Store multiple tasks in a Python list
* View all added tasks
* Delete tasks
* Exit the program

The project focuses on understanding how multiple items can be stored in a single variable using Python lists.

## 🛠️ Technologies Used

* Python 3
* Python Lists
* `append()`
* `pop()`
* `for` loop
* `while` loop
* Conditional statements
* User Input/Output

## 📋 Features

### Add Task

Users can enter a new task, which is added to the list using `append()`.

### View Tasks

All stored tasks are displayed using a loop.

### Delete Task

Users can select a task and remove it from the list.

### Exit

The user can exit the program from the menu.
